# OS-level kill test: the SDK Trader

Run: 2026-11-17T11:21:12.122Z
Node: local anvil fork; NOT mainnet. Throwaway keys, fake ETH, dev-only signer.
Result: **PASS** (7/7 checks)

What this shows: the real Trader runs a TWAP and a limit buy in a separate process that is killed with SIGKILL (once by itself right before a transaction would leave, twice from outside right after a slice was sent). Each fresh process is given no instructions and only calls resume(); it finds the TWAP and the order in the state files and finishes, every slice traded exactly once.

## Not covered

- Power loss or disk faults: SIGKILL ends the process but the operating system still flushes its writes.
- Kills at other moments than the three chosen ones; Redis-backed state (covered by unit tests, not by this OS-level run).
- Snipe and copy runners (they need a source supplied by the host).
