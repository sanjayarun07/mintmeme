## Not covered
- Replace-by-fee is not atomic: until a block is mined either transaction may win. The engine handles both outcomes, but a real network with other pending transactions, fee spikes or a private mempool can reject the replacement as underpriced; that path was not exercised.
- Only a pending transaction in the node's own pool is replaceable. A transaction already forwarded elsewhere (a relay or sequencer) may behave differently, and L2 sequencers with first-come ordering were not modelled.
- Solana has no replace-by-fee: a signed Solana transaction can only be left to expire.
