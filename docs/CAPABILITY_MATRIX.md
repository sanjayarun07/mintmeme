# Capability Matrix

Date: 2026-11-13. Verification so far is limited and read-only: Ethereum Uniswap V2 reads/simulations and Solana Raydium AMM v4 pool reads on mainnet (Alchemy, no funds moved), a Uniswap V2 buy/sell on a local mainnet fork, and tx-lifecycle checks on a local anvil and a Nitro testnode; each row below links its dated report. `npm test` (242 tests, 242 pass; includes mock-provider tests of the verification harness) exercises SimChain, fakes and recorded fixtures only; it moves no row above "Locally tested". No funds have ever moved on a public network.

## Legend (status ladder, lowest to highest)

| Status | Meaning |
|---|---|
| Unsupported | Decided out of scope or not possible on that chain/venue |
| Blocked by external dependency | Cannot start or finish without RPC access, keys, contract/ABI verification, indexer, or similar. No such dependency is provisioned |
| Implemented | Code path exists |
| Locally tested | Automated tests pass against SimChain (a simulated chain written in this repo) |
| Fork tested | Tests pass against a forked real-chain state at a pinned block |
| Testnet verified | Executed on the chain's public testnet with recorded tx hashes |
| Mainnet read-only verified | Quotes/simulations/reads compared with the real venue on mainnet; no funds moved |

Order of the ladder: Blocked/Unsupported < Implemented < Locally tested < Fork tested < Testnet verified < Mainnet read-only verified. "Locally tested" is not evidence about any real network.

Truthfulness rule: the only rows above Blocked are the generic models run on SimChain, the standalone chain-family fixtures, and the offline `packages/evm` calldata/math and scraper-with-fake-transport rows below. Chain IDs, contract addresses, RPC URLs, program IDs, and ABIs are deliberately NOT listed because none have been verified.

## How to move a row up the ladder

1. Blocked -> Implemented: provision the dependency (DEPENDENCY_REGISTER.md); write a `Venue` adapter for the real contract/program; add per-chain nonce/blockhash/seqno handling in the signing/submission path; verify ABIs/program IDs from the venue's official source and record the source + date in the repo.
2. Implemented -> Locally tested: unit tests against SimChain or a deterministic mock of the adapter's I/O boundary; negative cases (revert, tax token, stale quote).
3. Locally tested -> Fork tested: run the adapter against a forked chain at a pinned block (EVM: fork of real state; Solana: validator with cloned accounts; TON/Tron: equivalent local emulation where it exists). Assert quote vs executed output within a stated tolerance and fill derived from balance deltas. Record chain, block, tool version.
4. Fork tested -> Testnet verified: execute buy and sell with test funds on the public testnet if the venue is deployed there; store tx hashes and receipts in the repo. If the venue has no testnet deployment, the row stays at Fork tested.
5. Testnet verified -> Mainnet read-only verified: compare adapter quotes and simulated txs with the venue's own quoter / UI on mainnet at the same block, no funds moved, with a dated artifact. This is the ceiling of what this ladder certifies; funded mainnet trading is a separate readiness gate (PRODUCTION_READINESS.md).
6. Every promotion requires a dated evidence link; demote the row if the evidence is older than the venue's last known contract upgrade.
